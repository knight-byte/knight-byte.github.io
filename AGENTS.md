# Agent instructions

Static GitHub Pages portfolio. Plain HTML/CSS/JS, no build step.
Pages: `index.html` (home), `skills/index.html` (skill graph).

## Required skills
- **design-taste-frontend** (`.agents/skills/design-taste-frontend/SKILL.md`) —
  load before any UI/visual/layout/copy change to a page.
- **ponytail** — apply to all code changes: smallest working diff,
  no new deps, native HTML/CSS before JS, reuse existing styles/vars.

Conflict: ponytail decides how much code; design-taste-frontend decides how it looks.
