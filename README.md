This repository contains the source code for [abunachar.com](https://abunachar.com/). It is a lightweight, zero-dependency portfolio designed to reflect a true developer environment. It features a fully functional terminal interface alongside a clean, modern GUI card, powered entirely by Vanilla HTML, CSS, and JavaScript.

## ✨ Features

* **Interactive Terminal Shell:** A custom-built, interactive command-line interface. Users can type commands like `help`, `whoami`, `security`, and `neofetch` to learn more.
* **Dual-Mode UI:** Seamlessly toggle between the Terminal view and a standard GUI card view without reloading the page.
* **ANSI Color Palette:** The terminal is styled using authentic ANSI terminal colors (Green, Cyan, Yellow, Red, Blue, Magenta).
* **Zero Dependencies:** No React, no Vue, no build steps, and no NPM packages. Just pure web standards.
* **SEO Optimized:** Fully configured with JSON-LD structured data (schema.org), Open Graph meta tags, and semantic fallback content for crawlers.
* **Fully Responsive:** Adapts perfectly to mobile devices and varying screen sizes.
